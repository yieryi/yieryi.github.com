# 首屏 3D 重构方案（Digital Terrain Hero）

> 状态：初版完成，视觉调优中
> 开始日期：2026-11-13
> 主计划：[`REFACTOR_PLAN.md`](./REFACTOR_PLAN.md)
> 使用说明：[`USAGE.md`](./USAGE.md)

---

## 1. 目标

把首屏从「右侧 3D 球」升级为「全屏数字地形观测站」，让 3D 成为页面的主舞台，同时保持文字可读、性能可控、长期可维护。

核心体验：

1. 全屏 3D 场景，文字叠加在左侧。
2. 风格化雪山、山谷、河流、天空、少量鸟群。
3. 近景世界空间「观测者 + 坐标轴」，屏幕空间标签。
4. 相机使用 `rotate_forward` 固定循环，不开放用户控制。
5. 鼠标在首屏移动时，出现等高线式拖尾笔触，逐渐消散。
6. 日间/夜间主题共享同一场景，只切换光照与配色。
7. 移动端保留 3D，但降低地形精度、鸟群数量和 DPR。

## 2. 已确认决策

| 项目 | 决策 |
|---|---|
| 视觉风格 | **风格化数字地形**，不追求写实喜马拉雅 |
| Cornell box | **取消**，首屏不放 |
| 观测者 | **世界空间 3D 火柴人 + 坐标轴**，标签用屏幕空间投影 |
| 鼠标拖尾 | 做成**等高线笔触**，桌面端启用 |
| 移动端 | **必须有 3D**，不允许退化为纯静态海报；使用低画质档 |
| 相机 | `rotate_forward`，固定循环，无用户相机控制 |
| 模块化 | 拆成 `terrain / river / sky / birds / observer / camera / trail / palette / quality` |
| 首屏布局 | 3D 全屏铺满，文字左对齐 + 渐变遮罩 |

## 3. 场景设定

### 3.1 构图

- 全屏 canvas 作为背景。
- 文字在左侧 45%–55%，右侧/中右侧留出山体与观测者。
- 左侧渐变遮罩保证标题、正文、按钮可读。
- 右下角保留极简坐标/场景标识。
- 底部保留 `Scroll` 提示。

### 3.2 地形

- 程序化 heightfield，低多边形 + 平面着色。
- 雪线、岩石、谷地按高度和坡度混合。
- 中央偏右一条河谷，河面使用轻量流动高光 shader。
- 局部叠加很淡的网格，并用独立的等高线 shader 按世界高度绘制等高线（间隔约 1.3 场景单位），强调「数字地形」而不是纯风景。

### 3.3 天空

- 渐变天空穹顶 + 雾。
- 日间：冷白高光、浅蓝天空。
- 夜间：深蓝天空、月光、星点。
- 不使用完整大气散射，不加载 HDRI。

### 3.4 鸟群

- 桌面端 14 只 V 字鸟群，沿缓慢曲线路径移动 + 翅膀摆动；移动端不显示鸟群。
- 只做氛围，不抢主体。

### 3.5 观测者

- 世界空间火柴人，站在近景山脊。
- 三轴坐标架 + 脚下扫描环。
- 屏幕空间标签显示 `OBSERVER 01 / ALT`，通过投影跟随。
- 作用：提供尺度参照和视差锚点。

### 3.6 相机

使用 `ml-sharp/docs/camera_trajectory.md` 的 `rotate_forward`：

```text
t = (elapsed / duration) % 1
R = A_x * sin(2πt)
F = A_z * (1 - cos(2πt)) / 2
camera.position = base + right * R + forward * F
camera.lookAt(focus)
```

首屏参数：

- 周期 14 秒
- 横向/推近幅度比参考默认值更明显，保证肉眼可感知
- 桌面横向约 2.2、推近约 1.8；移动端约 1.3 / 1.0
- 无滚转、无垂直抖动
- 固定 focus

### 3.7 鼠标拖尾

- 独立 2D canvas overlay，不使用 WebGL。
- 桌面端 `pointer: fine` 启用。
- 2–3 条细线曲线，带轻微偏移，模拟等高线/墨迹。
- 指数衰减，约 0.8–1.5 秒消散。
- `pointer-events: none`，不影响点击和选择。
- `prefers-reduced-motion` 下关闭。

## 4. 模块划分

```text
src/scripts/hero/
  index.ts        # 生命周期、编排、主题切换
  quality.ts      # 高/中/低画质
  palette.ts      # 日/夜配色
  camera.ts       # rotate_forward
  terrain.ts      # heightfield + 雪线 + 等高线
  river.ts        # 河谷水面 + 流动高光
  sky.ts          # 天空穹顶 + 日/月 + 星点
  birds.ts        # 少量鸟群
  observer.ts     # 火柴人 + 坐标轴 + 屏幕标签
  trail.ts        # 等高线拖尾
  fallback.ts     # WebGL 不可用时的静态兜底
```

每个模块提供 `create / update / resize / dispose`（按需简化），由 `index.ts` 统一驱动。

## 5. 性能预算

- 首屏文字 LCP 不受 3D 阻塞。
- 3D 模块动态 `import()`。
- 地形三角面：桌面 3–4 万以内，移动端 1–2 万以内。
- 鸟群：桌面 14 只，移动端 0。
- 星点 ≤ 400。
- 无后处理；阴影关闭或单张低分辨率。
- DPR：桌面 ≤ 1.5，移动端 ≤ 1.25。
- 页面隐藏 / 离开视口暂停。
- 移动端仍渲染 3D，但降低精度和数量。

## 7.1 已知限制

- 日间地形偏白，岩石/阴影对比还可以继续加强。
- 河流白色流线仍偏图形化，后续可做更细的流动噪声。
- 鼠标拖尾首版偏细，可能需要更明显的发光/笔触层次。
- 移动端隐藏观测者与标签，同时不显示鸟群；保留地形/河流/天空 3D。
- 真机（iOS/Android）性能和发热尚未验证。
